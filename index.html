Direct P2P Stream

Files are chunked, SHA-256 hashed, and streamed directly from browser to browser via encrypted WebRTC DataChannels.

Security Architecture

DropLink utilizes standard WebRTC technology with DTLS/SRTP encryption built into modern browsers.

Signaling vs Data: DropLink signaling servers coordinate initial IP negotiation. File payload data flows directly between peers and is never saved or stored on any server.
SHA-256 Integrity Verification: Every file transferred has its cryptographic SHA-256 hash computed before and verified after transfer.

Privacy Policy

DropLink does not track users, log file transfers, or upload files to central server storage. Connections expire immediately upon transfer completion or cancellation.
